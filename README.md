# Standalone Bitwig Push

An open-source effort to turn Ableton Push 3 Controller into a self-contained, deeply integrated Bitwig Studio instrument.

The project starts with a reversible software proof on Linux: Bitwig Studio + DrivenByMoss semantics + a custom Push display compositor capable of mixing controller-native UI with selected regions of the real Bitwig/VST desktop. Only after that path is musically useful do we move inward to the Push 3 compute bay, internal USB carrier, alternative compute hardware, thermals, power, and battery operation.

> **Status:** project bootstrap. The first engineering target is an external Steam Deck proof over ordinary USB. No hardware modification is required for the initial slices.
